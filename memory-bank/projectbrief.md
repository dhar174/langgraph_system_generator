## Purpose

Use this file to describe the project at the highest level.
It should explain what is being built, why it exists, and where the project
scope begins and ends.

## When to Update It

Update this file when:

- the overall mission of the project changes
- the target outcome or primary deliverable changes
- important scope boundaries or non-goals change

## What to Include

- a short description of the project
- the primary goals of the project
- major boundaries, assumptions, and non-goals
- enough context for a new AI session or contributor to understand the project

## What to Avoid

- current task notes
- implementation details that belong in other memory-bank files
- raw code, long transcripts, or detailed meeting notes
- secrets, credentials, or other sensitive data
