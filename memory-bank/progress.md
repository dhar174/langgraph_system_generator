## Purpose

Use this file to track durable project progress over time.
It should summarize what is complete, what is still pending, and any ongoing
limitations or notable blockers.

## When to Update It

Update this file when:

- meaningful project milestones are completed
- new blockers or limitations are identified
- major pending work changes
- the overall status of the project shifts

## What to Include

- what is working
- what is incomplete or pending
- known issues and limitations
- concise milestone-level progress that future sessions should remember

## What to Avoid

- minute-by-minute task notes
- architecture descriptions that belong in `systemPatterns.md`
- detailed implementation logs
- secrets or anything that should not be persisted
