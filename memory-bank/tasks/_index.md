## Purpose

Use this file as the index for task-specific Memory Bank records stored in the
`memory-bank/tasks/` directory.
It should provide a quick overview of active, pending, completed, or abandoned
task files.

## When to Update It

Update this file when:

- a new task file is created
- a task changes status
- a task is completed, blocked, or abandoned
- task tracking needs to reflect the latest state of work

## What to Include

- a simple list of task files
- each task's current status
- short summaries that help the next session find the right task record quickly

## What to Avoid

- detailed task history that belongs inside the individual task file
- unrelated project documentation
- raw transcripts or large code snippets
- secrets or sensitive data
