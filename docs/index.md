# LangGraph System Generator Documentation

Welcome to the LangGraph System Generator documentation site.

LangGraph System Generator turns natural-language prompts into runnable
LangGraph system scaffolds, with notebooks, export artifacts, and reusable
workflow patterns for common multi-agent architectures.
